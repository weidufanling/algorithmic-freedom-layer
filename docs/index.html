02 / Install

Try the extension on real pages

Desktop Chromium browsers

Use the unpacked build on a desktop browser that allows developer extensions. Open the browser’s Extensions page, turn on Developer mode and select Load unpacked. Choose the unzipped folder containing manifest.json.

Download the beta build ↓

The download link will appear here when a release is available.

Firefox and Safari

Firefox desktop can load a temporary build for testing. It removes the extension when you restart Firefox. Safari on Mac needs an app build or a compatible temporary test setup. Safari on iPhone and iPad needs a separate Apple app build and distribution.

The controls work on web pages. They do not change the native YouTube or Reddit apps.

Site layouts can change, so a switch may miss some shelves. AFL does not change how either site ranks content on its servers.
