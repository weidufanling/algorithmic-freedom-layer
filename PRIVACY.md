# Privacy

The extension saves on/off preferences in local browser storage. It does not use an account, a server, analytics, or a browsing history log. The popup holds the links you enter while it is open. The extension sends no links or settings to Weidu Lab.

The extension can read parts of pages on www.youtube.com, m.youtube.com and www.reddit.com to identify the elements it can hide. The popup receives a filter status from the current page and does not save it. When you open the popup, the browser may provide the current tab URL and let AFL check the current Reddit page for a New feed link. The clipboard is written only when you choose Copy link. You paste links yourself.

The demo uses sample feeds. The cleaner runs on your device, and the demo does not save links or choices. Following an external link opens the named service under its own privacy rules. Opening Reddit's New feed is a normal visit to Reddit.

Feedback posted to the public issue tracker can be read by anyone. Omit private links, cookies, credentials, account details and sensitive screenshots.
