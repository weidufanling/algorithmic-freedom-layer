# Reporting a security problem

The current beta series receives fixes when available.

Use **Security > Report a vulnerability** in the project's GitHub repository if the private form is enabled. Include the AFL version, browser and operating system, the affected feature and a short way to reproduce the problem. Remove personal data, secrets and private URLs. If the form is unavailable, open a public issue asking for a private reporting route and omit the vulnerability details.

For ordinary bugs, use the issue tracker and follow the [contribution guide](CONTRIBUTING.md). If a site behaves unexpectedly, turn off the affected switch or disable AFL and reload the page.
